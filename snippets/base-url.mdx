The MarketBox API is served from:

```
https://apiv2.gomarketbox.com
```

Every example in these docs reads it from `MARKETBOX_API_URL`:

```bash
export MARKETBOX_API_URL="https://apiv2.gomarketbox.com"
export MARKETBOX_API_KEY="your-key-here"
```

<Note>
This is the production API. A key acts on the real data of its project. See
[Test keys and sandbox](/concepts/authentication#test-keys-and-sandbox).
</Note>
